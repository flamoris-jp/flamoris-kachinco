# ADR 0022: Caption styles (Issue #95)

Accepted for implementation after Akino confirmed scope and interaction on 2026-10-18.

- Caption owns an optional full `style`; null inherits the fixed legacy default: Yu Gothic, size 45, white, black outline 3.75, bottom center. Existing projects keep their current rendering and schema until a style is explicitly stored.
- Style sizes and outline/shadow offsets use reference pixels at a short canvas dimension of 1080; raster scale is min(width,height)/1080. X/Y are normalized canvas anchor coordinates, text width is a fraction of canvas width. Horizontal alignment is Left/Center/Right and vertical anchor Top/Center/Bottom. Top/center/bottom presets use Y .10/.50/.90. Text wraps inside the specified width; user line breaks remain intact.
- Native `PatchCaptionStyles(sequenceId, captionIds, patch)` applies only non-null patch fields to each caption's effective style. IDs are explicit, unique, nonempty and bounded to 4096. UI resolves selected/track/sequence scopes to those IDs. Changes are atomic, revision guarded and one Undo entry. Unchanged fields, timing and text survive. `SetCaptionStyle` replaces/resets one style; null resets to the default. No project-wide style mutation silently overwrites individual edits.
- Conditional schema v7 stores nullable `style` on every caption, all style fields required when non-null. v1-v6 continue to reject new fields and load with null styles. Projects without explicit styles retain their previous conditional v2-v6 encoding. v7 includes v6 title fields and v5/v4/v3 clip fields. Unknown style fields and invalid/oversized/nonfinite values fail before commit/load.
- UI exposes installed font names, numeric/HEX fields and color picker, anchor presets and detailed alignment. Timeline caption selection opens the right inspector. The caption list supports multiple selection. Font/field changes update the shared preview after commit without closing a dialog. Missing families show a warning and rasterize using Yu Gothic; glyph fallback remains WPF's responsibility. No font files are bundled.
- Evaluated captions carry styles into the existing shared caption rasterizer for CPU/GPU preview, frame capture and export. Default stacked caption behavior is retained; explicit styles position independently. Native remains editing/codec authority; WPF remains only the text raster adapter.
- MCP reuses `get_project` and `edit_batch` with two new typed commands. No new tool names. Hub's pinned edit_batch descriptor must be refreshed before new commands are advertised externally; production deployment and physical acceptance are separately reported.
- SRT remains text/time interchange; it does not retain styling. Save the Kachinco project or render video to retain appearance.

Validation: native patch/validation/codec/history contracts, managed roundtrip/evaluation/MCP tests, Windows raster comparison and UI smoke. Physical font appearance and real Hub transport are recorded separately from automated checks.
