# Kachinco application icon

Owner-approved FLAMORIS artwork, adopted on 2026-10-26 for the Windows application.
White/black with Lycoris-red accents and a transparent background.

- `Kachinco.svg`: editable vector source.
- `Kachinco_1024.png`: transparent master PNG.
- `Kachinco_SIZE.png`: 16, 24, 32, 48, 64, 96, 128 and 256 px variants.
- `Kachinco.ico`: one ICO containing those eight sizes.

The project embeds the ICO in the Windows executable (`ApplicationIcon`) and as a
WPF resource used by the main window. Rebuild/publish the application to apply it.
The PNG/SVG sources are retained here for editing and are not copied into the runtime bundle.
