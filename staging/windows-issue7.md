# Issue #7 — Windows hands-on checklist

この表は人間による確認用。CIの起動・座標測定成功は、視認性、自然な操作感、
実際の音声出力の合格を意味しない。実施するまでチェックを入れない。

実施記録: 日付 / commit / テスター / Windows版 / GPU / 画面解像度 / DPI / 音声出力先。
前提: [Windows起動手順](windows-production.md)。FFmpeg / ffprobeをPATHへ配置する。
短いMOV（映像）、WAV（音声）を使用し、MOV内の音声は別途WAVとして読み込む。
テストの小さいfixtureは `MediaVisualizationTests` が一時生成・削除する。

## 初回操作と保存

- [ ] 起動直後、「MOV / WAVを読み込む」が有効。新規Projectを先に作らず読み込める。
- [ ] ファイル選択をキャンセル、または不正な素材を選んでも空Projectが残らない。
- [ ] 読み込み後、素材一覧と「横長／縦長のシーケンスを作成」の案内が出る。
      中央の作成ボタンで進めても読み込んだ素材が保持される。
- [ ] シーケンスなしで保存／再起動／Openしても素材と作成案内が戻る。
- [ ] 素材読み込みをUndoすると初回状態に戻り、Redoで素材と案内が戻る。
- [ ] 作成したシーケンスは8秒。長い素材の配置で必要な長さへ伸びる。
      配置のUndo一回でクリップと長さが戻り、Redoと保存／Openで再現する。
- [ ] 明示的な「新規」は未保存変更の破棄確認を保つ。

## Timelineと素材の見え方

- [ ] S1 / V1 / A1の行上端・下端・区切りがレーンと一致する。
      トラックを追加し縦スクロールしてもずれない。
- [ ] MOVは実際の先頭フレームと名前、WAVは実際の波形と名前が見える。
      選択枠・移動カーソル・左右トリム位置を空レーンと区別できる。
- [ ] 表示準備中／素材不在／生成失敗は説明が出る。素材を再リンクすると表示が更新される。
- [ ] WAVの無音・大きい音が区別できる。開始位置のトリム確定後はSource Inに対応した部分が見える。
- [ ] 幅の短いクリップでも時間上の長さが膨らまない。重なりや名前の切れ方を確認する。
- [ ] ズーム／Fit／横スクロール後、同じruler位置の再生ヘッド・クリップ開始が一致する。
- [ ] Snapを外して指定時刻へdropする。ポインターのフレーム位置と配置結果が一致する。
      Snapを戻すと予告枠と最終結果が一致し、不適合トラックへのdropは拒否される。
- [ ] ドラッグで移動、両端トリム、Escapeによる取消を試す。
      一操作一Undoで戻る。表示生成が完了する瞬間もドラッグが途切れない。
- [ ] Save／Open／Undo／Redo後も配置、Source In、duration、字幕、Clapper、Recipeが保持される。

## 再生と失敗フィードバック

- [ ] 未準備状態からPlayまたはSpaceを押すと「準備中→描画中（進捗）→準備中→再生中」と進む。
      長い準備中もUIが応答し、Stopで取り消せる。完了済み部分は100%表示になり得るが、
      音声・映像のまとめ処理中という説明が続く。
- [ ] 「再生中」で映像が変化し、再生ヘッドが進み、WAVが実際の出力先から聞こえる。
      映像と音声の同期を人の目と耳で確認する。
- [ ] Space／Pause、再開、Stop、終端、コマ送り、rulerでのseekが自然に動く。
      停止／一時停止をラベルでも区別できる。入力欄のSpaceは再生操作にならない。
- [ ] 「プレビュー準備」は完了しても自動再生しない。
- [ ] 準備中に編集／Undo／シーケンス変更／Stopを行っても古い映像が後から再生されない。
      準備中の書き出し開始も古いautoplayを取り消す。
- [ ] 素材不在・FFmpeg不在・デコード失敗で原因が表示される。修正後、Playで再試行できる。
- [ ] ExportとPreviewが同じ配置・合成・字幕・WAVを反映する。
      長いシーケンスの準備速度は別途記録する（リアルタイム性能は今回の保証外）。

## FLAMORIS-familyの最終目視

- [ ] Cutworkと並べ、Menu、ToolBar、contextual controls、右Inspector、下Status、
      余白、境界、hover、選択、FLAMORIS accentに統一感がある。
- [ ] 1320×820と最小980×640、100%／150%／200% DPIで情報密度・文字のコントラスト・
      toolbar overflow・パネルサイズ・操作の見つけやすさを確認する。
- [ ] 日本語が初期表示。Englishへ切り替え、shell・初回案内・再生状態が切り替わる。
      日本語へ戻せる。Project内の名前や内容は翻訳されない。
- [ ] before/afterを同条件で安定取得できる場合だけcommit・DPI・ウィンドウサイズ付きで添付する。

制限: 初期動画表示は素材の先頭ポスター一枚。波形はmono概要で、トリム中のsource-aware
再描画や高ズームのサンプル詳細は未実装。旧来の副ダイアログ・domain diagnosticsの完全英訳も対象外。
